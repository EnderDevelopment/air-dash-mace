# Air Dash Mace Plugin

This is a Minecraft plugin that adds a custom Dash Mace item. When a player holds the mace and right-clicks while in the air, they are launched forward in the direction they are looking. The plugin includes a 3-second cooldown and is available for both Java Edition (as a Paper plugin) and Bedrock Edition (as a separate addon).

## Install

### Java Edition (Paper 1.21+)

1. Download the `plugin.jar` file from the release.
2. Place the jar file into your server's `plugins` folder.
3. Restart your server.

### Bedrock Edition

1. Download the `.mcaddon` file from the release.
2. Import the `.mcaddon` file into Minecraft Bedrock Edition (double-click to import).
3. When creating or editing a world, navigate to Behavior Packs and enable the "Dash Mace" pack.
4. Ensure "Beta APIs" (Holiday Creator Features) are enabled in the world settings.

## Use

### Java Edition

1. In-game, run the command `/dashmace` to receive the Dash Mace.
2. Hold the mace in your main hand.
3. Jump into the air and right-click to dash forward.
4. Wait 3 seconds between dashes (cooldown).

### Bedrock Edition

1. Give yourself the item with the command `/give @s dashmace:dash_mace`.
2. Hold the mace in your main hand.
3. Tap/right-click while in the air to dash forward.
4. Wait 3 seconds between dashes (cooldown).
